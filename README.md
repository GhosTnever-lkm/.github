# GhosTnever Community Health Files

Shared contribution and support guidance for public repositories under [GhosTnever-lkm](https://github.com/GhosTnever-lkm).

GitHub surfaces these community health files on repositories that do not provide their own equivalent files. This repository keeps the common rules in one place so contributors can find consistent guidance.

## What's included

- `CODE_OF_CONDUCT.md` — respectful, constructive participation and how maintainers may enforce the rules.
- `CONTRIBUTING.md` — contribution scope, development checks, and pull request checklist.
- `SECURITY.md` — supported versions and private vulnerability reporting guidance.
- `PULL_REQUEST_TEMPLATE.md` — summary, testing, and contributor checklist.
- `.github/ISSUE_TEMPLATE/` — structured bug reports and feature requests.

## Contributing

Open an issue before changing shared policy or adding a new template. Keep edits clear, reusable across different projects, and free of project-specific assumptions. For security reports, follow `SECURITY.md` rather than posting details publicly.
